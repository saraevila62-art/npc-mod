# Yuno Gasai Addon — prototype for Minecraft 1.21.1 NeoForge

Это исправленный демонстрационный проект на основе присланного ZIP Qwen.

## Что уже добавлено в пример
- Исправлен путь `src/main/resourses` → `src/main/resources`, чтобы Gradle включал ресурсы.
- Добавлено яйцо призыва `Юно Гасай` (`yandereaddon:yuno_spawn_egg`).
- Добавлена регистрация атрибутов сущности, необходимых для моба.
- Рендерер больше не использует модель/текстуру зомби; подключена player-модель и отдельная текстура `yuno.png`.
- Добавлено сохранение UUID игрока-владельца; NPC не присваивает себе случайного ближайшего игрока после загрузки мира.
- Исправлен каталог поиска анимационных JSON с `lovsplayer/animations/featured` на фактический `lovsplayer/motiondata/featured`.
- Обновлены русские и английские названия сущности и яйца.

## Как призвать Юно
- В творческом режиме открой вкладку «Яйца призыва» — там будет яйцо «Яйцо призыва Юно Гасай».
- Либо введи команду: `/give @s yandereaddon:yuno_spawn_egg 1`
- Возьми яйцо в руку и нажми ПКМ по земле. Юно появится рядом.
- После появления нажми ПКМ по Юно, чтобы назначить себя её владельцем.

## Установка/сборка
1. Нужны Java 21 и Minecraft 1.21.1 NeoForge.
2. Открой папку проекта в IntelliJ IDEA как Gradle-проект или запусти `gradlew.bat build` в Windows.
3. После успешной сборки JAR будет в `build/libs/`.
4. Положи собранный JAR в `mods` вместе с NeoForge.
5. В творческом режиме найди яйцо «Яйцо призыва Юно Гасай» или используй `/give @s yandereaddon:yuno_spawn_egg`.

## Важные ограничения
- Это **самостоятельный прототип NPC**, а не доказанная интеграция с закрытым NPC-контентом LovsPlayer. В JAR LovsPlayer 1.5.0, который был приложен, не оказалось платного NPC-контента из Boosty.
- Логика отношений/состояний из Qwen сохранена, но загрузка и проигрывание анимаций LovsPlayer пока не реализованы: исправление каталога — только первый шаг.
- Текстура — простая тестовая 64×64 пиксельная заготовка, а не финальная детализированная модель/скин из Project Lovs.
- Сборку в этой среде проверить не удалось: Gradle Wrapper попытался скачать Gradle 9.2.1, но сетевой доступ к `services.gradle.org` недоступен. Поэтому этот архив — исходный проект-пример, не готовый проверенный JAR.

## Основные файлы
- `YandereAddon.java` — регистрация сущности и яйца призыва.
- `entity/YandereNpc.java` — поведение, отношения и сохранение владельца.
- `brain/` — состояния и показатели отношений из исходного проекта.
- `client/YandereNpcRenderer.java` — рендеринг и текстура Юно.
- `resources/assets/yandereaddon/textures/entity/yuno.png` — тестовая текстура.
